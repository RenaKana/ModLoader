# ModLoader 图标

`app-master.png` 是选定的模块 M 主图标；`tray-master.png` 去掉中央浅色切片，供小尺寸系统托盘使用。两张母版由内置 ImageGen 生成并按选定的 A 方案精修。

运行 `npm run build:icons` 生成窗口与界面 PNG、Windows 多尺寸 ICO 和托盘 ICO。脚本仅缩放、转换格式，保留母版透明通道；`npm run package` 会先执行此步骤。

## 精修提示词

主图标：保留蓝色圆角底板、粗白色模块 M 和中央浅蓝切片；统一左右轮廓、曲线与笔画宽度，扩大 M 与切片之间的蓝色间隙；不增加文字、阴影或新元素，底板外保持透明。

托盘图标：保留主图标的蓝色底板和白色 M，只移除中央浅蓝切片以适配 16–24px；其余比例和透明背景保持一致。
